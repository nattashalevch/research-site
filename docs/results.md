# Результаты эксперимента

Версия сайта: **1.1**

В версии 1.0 мы измеряли время сборки и размер сайта на генераторе MkDocs с темой Material. В версии 1.1 добавлен второй эксперимент: проверка русскоязычного поиска.

## Время сборки

Измерения выполнялись на MacBook Air, Python 3.10, MkDocs 1.6.1, Material 9.7.7. Перед каждым запуском каталог сайта удалялся, поэтому сборки шли с нуля.

| Запуск | Время сборки, с |
|---|---|
| 1 | 0.79 |
| 2 | 0.72 |
| 3 | 0.92 |
| Среднее | 0.81 |

## Русскоязычный поиск

Мы проверили, находит ли встроенный поиск страницу, если форма слова в запросе отличается от формы слова в тексте. Сравнивались настройки `lang: ru` без стеммера и `lang: ru` со стеммером в `pipeline`.

| Запрос | Слово на странице | Без стеммера | Со стеммером |
|---|---|---|---|
| сборка | сборки | нет | нет |
| генератор | генераторов, генераторе | да | да |
| измерение | измерения | нет | нет |
| размеры | размер, размера | нет | нет |
| измерять | измеряли | нет | нет |
| сборк (контроль) | сборки | да | да |
| измер (контроль) | измерения | да | да |

## Обсуждение

Время сборки в трёх запусках различается не более чем на 0.2 с. В поиске найдено 1 из 5 запросов в обеих настройках. Контрольные запросы показывают, что поиск работает по началу слова: изменение окончания запроса страницу не находит. Включение стеммера изменило конфигурацию индекса, но результаты не изменило.

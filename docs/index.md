# Публикация результатов исследований с помощью статических сайтов

**Авторы:** Левченкова Наталья, Кильдеева Дарья

**Группа:** P4107

Этот сайт создан в рамках Задания 1: «Генераторы статических сайтов для публикации результатов исследований».

## Выбранные задания

- **Исследовательское задание T1:** сравнительный анализ генераторов статических сайтов 
- **Практическое задание P5:** версионирование опубликованных результатов (mike) и локальный поиск с поддержкой русского языка.

## О проекте

Здесь мы публикуем материалы работы: сравнение генераторов статических сайтов, настройку автоматической публикации сайта и версионирование результатов.
